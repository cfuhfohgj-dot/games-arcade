# Games Arcade

A mobile-first arcade of small browser games with an Arabic, right-to-left interface. Single-page HTML, CSS and JavaScript, no build step and no dependencies.

## Features
- Game menu with glass-style cards
- Touch controls, built for phones
- Score and best-score tracking
- Includes 2048 and canvas-based games

## Run
Open `index.html` in a browser, or enable GitHub Pages for this repo.
